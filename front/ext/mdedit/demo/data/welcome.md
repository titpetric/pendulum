# Welcome

This file is here so the demo server has something to index. Edit it, hit
Save, and the bytes land back on disk.

Things worth trying:

- select a word and press **B**
- paste a screenshot straight into the text
- drop an image file onto the textarea
- press the pilcrow to hide the markers, and click the `H1` label on this
  heading to change its level

> With the markers hidden the document reads as a document and the writer
> goes on editing it where it stands: the heading above names its level at the end of
> the line, and a hash or a Backspace at the head of the text moves it.

| Tool | What it writes |
| --- | --- |
| B | `**bold**` |
| H | cycles `##` and `###` |
| { } | a fenced code block |
